# Targeted functional review — 2026-10-04

## Scope

Model stepping, material/flow wiring, painting, readouts and reset; existing CPU/kernel suites.

## Finding and fix

### Clock advancement

`FieldSimulationModel.advance()` forced at least one engine substep even when dt was zero or negative. Calling step(0) therefore changed the field and elapsed time. Nonpositive and nonfinite durations now return before integration. A regression checks both the clock and painted field.

## Validation

- `npm run lint`, `npm run check`, `npm test` (96 passing tests), and `npm run build` passed.
- `npm run test:fuzz:quick` passed: pointer and keyboard smoke, 10 seconds each, on an isolated port. An initial shared-port attempt lost its server before the keyboard test; the isolated rerun passed.
- The new regression failed with the original behavior and passed with the fix.
- Checks used the available Node 22.12.0 runtime; the repository declares Node >=24.

This was a targeted source and regression review, not an exhaustive audit.
